Project Title:
             E-commerce Website
Project Description:
               E-commerce product discovery platform with intelligent search and personalized
              recommendations. 
Features   :
   User registration and login
   Product search
   Category filtering
   Product comparison (up to 3 products)
   Wishlist
   Shopping cart
   Checkout
   Order management
   User-specific cart/orders
    Responsive design
How to Use  :
When you open the application, you will land on the Home page.
Navigate to the Products page to browse and search for products.
The Products page includes category filter buttons that open a category sidebar, allowing you to filter products by category.
You can also use the search input on the Products page to search for any product.
The navigation bar is available at the top of the application. It includes a product search input where you can enter a product name and press Enter to search.
The navigation bar also includes a Login link. If you do not have an account, you can register using the Register option.
After logging in, the navigation bar changes to display options available to the logged-in user. User login information is stored in local storage.
You can compare up to three products at a time.
You can add products to your Wishlist and move them from your Wishlist to the Cart.
Products in the Cart can be purchased by proceeding to Checkout and placing an order.
Some functionalities are still under development and will be completed in future updates.



Technologies Used  :

       React Router
